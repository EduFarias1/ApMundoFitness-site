# ApMundoFitness — loja virtual

## Como usar
1. Abra `index.html` em um navegador ou publique a pasta em uma hospedagem estática.
2. A área administrativa fica em `admin.html`.
3. Login inicial: `andreapaula`
4. Senha inicial: `2707`
5. O WhatsApp ainda está com número de exemplo. Altere pelo painel administrativo.
6. Produtos, configurações e carrinho usam localStorage neste protótipo.

## Importante para produção
Este projeto já possui a estrutura visual e as interações principais, mas a autenticação e o banco de dados estão no navegador. Para uma loja publicada de verdade, recomendamos conectar o painel a um backend seguro (ex.: Supabase/Firebase/Node + PostgreSQL), com autenticação server-side e armazenamento de imagens.
